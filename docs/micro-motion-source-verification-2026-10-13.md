Ограничения исходной русской копии: п. 1.5 и табл. 10-1 называют диапазон 18–100 В переменным током, хотя заголовок говорит AC/DC; на с. 8 текст использует 0,5 мА, а формула — 0,5 А. В п. 7.2 для HART указано 250–600 Ом, а подпись рис. 7-2 — максимум 820 Ом. Эти расхождения не разрешены карточкой, численные инструкции по питанию и нагрузке HART не внедрены. Схемы выходов, опасные зоны, настройка и калибровка требуют соответствующих документов конкретного исполнения.

Воспроизведение: `python scripts/extract-micro-motion-illustrations.py --source <PDF>`.
Скрипт проверяет точный SHA-256 до создания выходов и число страниц, рендерит оригинальные области в RGB при 216 dpi (PyMuPDF 1.26.6), обновляет только собственные записи illustration-sources.json. Проверены повторное байт-идентичное извлечение, совпадение PNG с хешами реестра и отказ для другого PDF до записи. Две иллюстрации занимают 406908 байт.

Проверка приложения выполняется контроллером в GitHub Actions. RED: run 38355657341, новые карточки отсутствуют; общий результат GREEN фиксирует контроллер после публикации реализации. Локальные Flutter/pub/APK-команды не выполнялись.
