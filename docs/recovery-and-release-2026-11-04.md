На восстановленной актуальной ветке последовательно выполнены:

- `flutter analyze --no-pub`: без замечаний, exit 0, 68,7 секунды.
- `flutter test --no-pub --reporter expanded`: **319/319**, exit 0,
  54 секунды выполнения тестов, ошибок и пропусков нет.
- `dart format --output=none --set-exit-if-changed lib test integration_test`:
  56 файлов, 0 изменений, exit 0.

Исходный код приложения в этом этапе не менялся. Первый release-запуск с
`--no-pub` завершился ошибкой Java: автоматически созданный registrant всё ещё
ссылался на `IntegrationTestPlugin`, который Gradle исключает из release.
В установленном Flutter 3.41.6 `--no-pub` также пропускает пересоздание
platform tooling в release-режиме. Повтор выполняется обычной командой
`flutter build apk --release --target lib/main.dart`; регистрация тестового
плагина при этом удаляется средствами Flutter. Та же коррекция внесена в
`scripts/build-android.ps1`, чтобы повторная сборка после тестов не возвращала
этот отказ. Защита подписи и исходный ключ сохранены.

Повторная release-сборка завершилась успешно, exit 0, Gradle 211,1 секунды.
Java registrant автоматически пересоздан без `IntegrationTestPlugin`.
Синтаксис исправленного PowerShell-сценария проверен штатным парсером.
