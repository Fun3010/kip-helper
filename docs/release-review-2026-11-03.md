# Ревью перед выпуском Android и Windows

Дата: 03.11.2026, Europe/Moscow. По запросу владельца проверяется весь проект:
корректность и простота кода, удобство, дизайн и полнота рабочих сценариев.
Это единый реестр замечаний. Совместимый Android release пока заблокирован
отсутствующим паролем исходной подписи; это не недостаток анализа кода.

## Основание

Независимо просмотрены весь `lib/`, новые изменения, тесты, Windows runner и
правила архивации. Отдельный обзор проверил интерфейсы и существующие снимки
экранов. Базовая версия `bf28e2b` прошла анализ и 258 тестов до новых изменений.
Ревью исходников не заменяет запуск нативных PDF и приложения на устройстве.

## Повторное ревью и обнаружение при запуске

Исправления R01–R09 и затем R11/R10 прошли узкие независимые ревью:
новых подтверждённых существенных регрессий не найдено. На 7379ba3 полный
набор дал 304 успешных теста. После исправления adc1d1d свежий полный
прогон дал **305/305**, анализ всего проекта — без замечаний (оба exit 0).

Первая Windows integration-проверка на `d7b4076` действительно собрала и
запустила приложение, затем обнаружила R11 в pdfrx `PdfTextSearcher`.
До исправления дальнейшие нативные испытания были приостановлены.
Этот результат отдельно показывает границу анализа и
widget-тестов; их успешность не считалась готовностью поставки.

Исправление R11 прошло воспроизводимый RED→GREEN регрессионный тест,
целевой набор 11/11, анализ и отдельное узкое ревью жизненного цикла.
Нативный повтор прошёл из реальной ASCII-папки на 7379ba3: Windows — два
сценария, Android — PDF-сценарий; Windows-only ветка на Android пропускается.
PDFium действительно отрисовал страницы, поиск/переход/скан/ошибка/повтор
проверены. Тест использует реальные плагины и частное хранилище, но обходит
системный выбор файла и не доказывает перезапуск всего приложения.

## Лаконичность и архитектура

Существующие разделение формул, содержимого, интерфейса и хранения подходят
проекту. Масштабная перепись не требуется. Исправления должны сохранять один
набор коэффициентов НСХ, не подменять неподтверждённые сведения производителя
универсальными инструкциями и не создавать лишних слоёв без практической пользы.

## Отдельные условия выпуска

- Совместимый Android release требует исходного ключа. Его зашифрованная копия
  найдена в Notion и повторно сохранена в Drive; пароль пока не восстановлен.
- Android Gradle отказал в пути с кириллицей; Windows CMake не собрал проект
  из корня subst-диска. Реальная ASCII-папка решила обе проблемы; контрольные
  Windows release и Android debug собраны на adc1d1d с lib/main.dart, exit 0.
- Восстановлены 4/21 исторических PDF и 3 дополнительных точных документа.
  Пока отсутствуют 17 исторических PDF и 13 фотографий; перенос всех оригиналов
  не подтверждён.
- Облачные копии и шаги продолжения описаны в `docs/cross-device-storage.md`.

Физический телефон, вход с ноутбука, промышленное оборудование и публикация
в магазине не проверялись. Зелёные проверки не заменяют восстановление подписи.
Файлы поставки и точные результаты запуска — `release-delivery-2026-11-03.md`.
