# Необработанные фотографии

Загружайте сюда новые фото оборудования, шильдиков, панелей и схем.
Сортировка и переименование не обязательны. Связанные снимки можно положить
в одну подпапку и добавить пояснение в текстовом файле.
После просмотра оригиналы переносятся в `docs/Оборудование/<семейство>/Фото/`.
