## Границы результата

PR #2 добавил связи каждого абзаца четырёх эталонных карточек с источниками;
PR #3 уточнил страницы, включая этапы RUN SIPART. Эта пачка закрывает две
оставшиеся привязки. Остальной каталог не объявляется полностью проверенным.
Исходные PDF и OCR остаются вне Git; в репозитории сохранены идентификаторы,
локаторы и итог визуальной сверки. Результаты CI фиксируются в журнале проекта.

Следующий согласованный этап P1: избранное, недавние приборы и сохранение
быстрого доступа после перезапуска.
