# Метран-150: карточка и схемы

Добавлена карточка `metran150` для моделей 150CD, 150CG, 150TG и 150TA по базовому РЭ СПГК.5225.000.00 версии 4.23. Специальные требования HR7 находятся в самостоятельном приложении Н, которое в этой итерации не переносится. Для 150CDR/150CGR/150TGR/150TAR/150L используется другое РЭ; эти модели явно исключены из области карточки.

## Проверенный источник

Официальная страница: https://metran.ru/catalog/pressure/metran-150/ — документ «Руководство по эксплуатации Метран-150 (опция HR5)».
PDF: https://metran.ru/upload/iblock/794/0iy0f9l4wu0yx9eykbyaxat1j9ddpqh0.pdf
150 страниц. Версия 4.23 указана на титуле; календарная дата редакции не установлена.
SHA-256: `8fdaa068e0441171c30ea1fe8671e0c9c06c0589ddc1d36fd4e3dee6c949e721`.

Это новый снимок документа изготовителя. Исторический `71450_metran150.pdf` (127 страниц, SHA-256 `4964a928894ddcef35ef72c975eec6e04502ab980547db60c04ffdc9278bc873`) из старого реестра этой работой не заменён и не использован как источник. Его номера страниц не смешиваются с новым РЭ.

| Ресурс | Рисунок | РЭ / PDF, от 1 | Область в PDF-точках |
|---|---|---|---|
| metran150-current-0-5.png | Г.1, 0–5 мА, четырёхпроводная линия | 89 / 89 | 135, 155, 515, 365 |
| metran150-current-4-20.png | Г.2, 4–20 мА, двухпроводная линия | 89 / 89 | 135, 412, 515, 625 |

Номера клемм, полярность, нагрузка, БП, коммуникатор и подписи сохранены без перерисовки. Схемы не объединены. Для Exia РЭ направляет к приложению Е; общая схема Г не заменяет его требований.

Происхождение и SHA-256 PNG записаны в `illustration-sources.json`. Генератор: `python scripts/extract-metran150-illustrations.py --source <PDF>`. Рендер 216 dpi, белый RGB, без поворота. Хеш исходника проверяется до создания выходов. Повторное извлечение сохранило байты manifest и рисунков; неверный PDF отвергнут до записи. Размер двух PNG — 337310 байт.

## Сведения карточки

| Раздел | Проверенное основание |
|---|---|
| Область применения, отдельный HR7 | с. 3 |
| Местная настройка / HART5 | пп. 1.2.39–1.2.40, с. 27 |
| Выбор схем и герметизация | п. 2.4.8, с. 61; приложения Г/Е |
| Фиксированный ток многоточечного режима | п. 2.4.10, с. 62–63 |

Каждый абзац имеет адресуемый источник. Рабочий чек-лист явно отмечен и не приписывается изготовителю. Пошаговая калибровка и универсальные значения питания не добавлялись.
