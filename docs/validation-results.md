## Исправленные причины ошибок

Отсутствовала зависимость `url_launcher`, исходник содержал ошибки скобок
и недопустимый `const`, шаблонный тест обращался к отсутствующему `MyApp`.
В README и `.gitignore` оставались маркеры конфликта.

Неверный ввод превращался в ноль; NaN/Infinity не отклонялись. Поиск без
совпадений возвращал весь список. Не освобождались контроллеры калькуляторов.
Ошибки внешнего обработчика ссылок вызывали необработанное исключение.

НСХ 100П ошибочно использовала коэффициенты Pt100. Линейное приближение
заменено характеристиками стандарта. Обратный расчёт на границе диапазона
преобразователя учитывает численное округление.

Исправлены логика реле исправности СУ-1С, единицы защит СОКРАТ,
трактовка RUN как этапа SIPART. Данные ограничены указанными исполнениями.
