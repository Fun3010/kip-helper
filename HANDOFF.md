2. Перед финальным выпуском решить интеграцию PR в основную ветку; сейчас работа сохранена в опубликованной ветке и черновике PR №12. Не пересобирать неизменённый код только ради нового commit документации.
3. Для совместимого Android release восстановить исходный ключ с сертификатом SHA-256 `10bb36a1b9b994a859b45517623666d6323e997e2e1c73cb273e9a1939b8cd7c`. Зашифрованная копия сохранена в Notion и Drive; её прежний пароль не найден. Пока исходный ключ не восстановлен и сертификат не проверен, подписанный APK для обновления существующего приложения не готов. Не заменять ключ и не обходить проверку подписи.
4. При дальнейших изменениях обновлять Git, Drive и Notion, фиксируя commit и контрольные суммы. Автоматической синхронизации между ними нет. Начинать с актуальной ветки, не с исторического ZIP октября.
