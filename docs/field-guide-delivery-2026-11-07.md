# Полевой формат: первый рабочий этап — 07.11.2026

Ветка: `feat/field-guides-2026-11-07`, исходная main — `21d10e3`.
Владелец одобрил аудит и макет, затем поручил реализацию. Это первый законченный
этап общего формата и SIPART, а не заявление о полной переработке всех технических
процедур остальных 12 приборов.

## Что работает

- Во всём каталоге подробности источника раскрываются по нажатию. Статус рабочего
  чек-листа и ограничения не выдаются за проверенную процедуру изготовителя.
- RUN1–RUN6 — отдельные читаемые записи; RUN6 только для -Z P02. Так же оформлены
  аварии и регистры СОКРАТ, контакты/состояния СУ-1С и коды СТМ-30.
- SIPART: WAY — 8 шагов, turn — 7. Действие, орган управления, характер нажатия,
  исходный рисунок, ожидаемые показания и источник. Оглавление не обходит выбор
  исполнения и подтверждение условий. Нижняя навигация не требует прокрутки источников.
- При запуске инициализации показаны Strt, затем ожидание FINSH; выход описан в MAN.
  Прерывание на приборе — отдельная памятка с явной применимостью к незавершённому процессу.
- Источник рисунков — официальные РЭ, не генеративный макет. Реестр проверки:
  `sipart-field-source-verification-2026-11-07.md`, координаты и суммы:
  `sipart-field-assets-2026-11-07.json`.
- Поисковый запрос кода переносится из каталога и поднимает нужный пункт выше,
  сохраняя остальной контекст. Имя прибора не превращается в пустой внутренний фильтр.
- В библиотеке этого прибора связанные PDF идут первыми; связь не подтверждает
  редакцию документа и не заменяет сверку исполнения.

## Проверки и ревью

Последовательный полный локальный набор после исправлений ревью: **336/336**, без
ошибок/пропусков. Дополнительный сценарий захвата рабочих экранов: **1/1**.
Проверены светлая/тёмная темы, 320 dp / 225%, нижние кнопки, смена исполнения,
отмена подтверждения, переходы по оглавлению и памятка прерывания. Источники
по-прежнему доступны по раскрытию, а отсутствие URL не обещает открыть PDF.

Независимый просмотр источников и кода выявил три существенных замечания:
дублирование действий SIPART вне условий, исчезающую оговорку уставок и запрос
имени, открывающий пустой фильтр. Они исправлены. Дополнительно условия доступны
повторно после начала, а памятка прерывания уточняет применимость.

PNG в `build/qa/field-entry-dark.png`, `field-start-dark.png`, `field-run2-dark.png`
получены настоящим Flutter-рендерером из текущего приложения, с загруженными
исходными изображениями. Это не снимки физического телефона. При настройке среды
первоначально не загрузился PDFium; официальный бинарный архив закеширован для
штатного hook. Пакеты восстановлены в точных версиях pubspec.lock с проверкой SHA-256.
Код зависимостей и подпись приложения не подменялись. Один из повторных прогонов выявил гонку существующего теста перепривязки PDF: проверка диска выполнялась до завершения асинхронной записи. Тест теперь ожидает завершения настоящей транзакции; код хранилища не менялся.

## Что не входит в эту поставку

Новые полные кнопочные процедуры РэмТЭК, Biffi, газоанализаторов и остальных моделей
ещё требуют такой же сверки РЭ. ИВА-8 остаётся обзором по описанию типа. Это
сохранённые границы содержания, а не незаметно заполненные предположениями инструкции.

Физический PS2, реальный Android, Windows native и реальный технологический процесс
в этой среде не проверялись. Новый совместимый подписанный APK не выпускался:
исходный ключ остаётся на прежнем ПК, guard сохранён. Версия/формулы/package ID
не менялись. Прежний APK 1.3.0+5 не содержит этих новых экранов. Слияние в main и
публикация в магазине не выполняются этим этапом.

Следующий порядок: посмотреть рабочие экраны и проверить пилот на целевом устройстве;
собрать APK исходным ключом; затем расширять проверенные процедуры на остальные
приборы по реестру аудита. Обновления состояния и ссылки на текущий PR/архив
сохраняются в проектной странице Notion.
