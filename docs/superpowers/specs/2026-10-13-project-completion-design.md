# Завершение текущей дорожной карты

Основание: пользователь попросил завершить проект целиком. Объём — пять этапов
`docs/development-roadmap.md`. Команда от 03.11.2026 разрешает завершить все этапы,
выполнить локальные проверки и выпустить APK. Существующий ключ подписи сохраняется.

## Результат

1. OPTIFLEX 1300 C и Micro Motion соответствующей исходному РЭ серии пополняют
   каталог: точная модель/редакция, подтверждённые абзацы, исходные схемы с увеличением.
2. Личные заметки доступны из каждого прибора, сохраняются после перезапуска,
   отделены от заводского содержания. Ошибка сохранения видима; несохранённый текст
   не теряется молча при выходе. Очистка требует подтверждения.
3. Пошаговые сценарии имеют область применимости, условия начала, действия,
   ожидаемый результат и ссылки на источник. Поддержаны подключение, настройка /
   калибровка и диагностика для тех исполнений, где источник подтверждает шаги.
   Неподтверждённые шаги не заменяются универсальными советами.
4. Офлайн-руководства импортируются пользователем через системный выбор PDF.
   Копия сохраняется в данных приложения; список содержит название, размер,
   связь с прибором. Просмотр, переход к PDF-странице, поиск по текстовому слою
   работают без сети. Скан без текста явно помечается; OCR не считается доказательством.
   Удаление локальной копии требует подтверждения. Импорт не меняет исходный файл.
   PDF не вкладываются в публичный git и не увеличивают APK на размер всей библиотеки.
5. К существующим проверенным расчётам добавляется таблица НСХ с опорой на тот же
   доменный расчёт; поддержаны выбор НСХ, границы и шаг, ограничен объём таблицы.

## Архитектура и проверка

Flutter/Dart, модульные страницы и сервисы, существующие модели карточек сохраняются.
Заметки используют shared_preferences; PDF используют системный выбор, приватный
каталог приложения и pdfrx. Новые зависимости фиксируются и проверяются в CI.
Узкий экран 320 px, две темы и увеличенный шрифт входят в widget-проверки.
Нет сетевой отправки измерений/заметок. По команде от 03.11.2026 проверки Flutter,
получение зависимостей и сборка выполняются локально; нативные импорт/рендеринг
проверяются на доступном Android-эмуляторе. Проверка физического телефона
фиксируется отдельно. Финальный release использует только исходный ключ подписи.

## Границы готовности

Готовность кода означает выполненные пункты, чистый анализ, тесты и независимое ревью.
Она не означает проверку на физическом телефоне или универсальную применимость всех
карточек к любому исполнению. Пробелы исходных документов остаются явно обозначенными.

## Уточнение поставки от 03.11.2026

Владелец запросил Android APK **и версию для ПК**. Для текущего окружения ПК
означает Windows x64: тот же офлайн-каталог, расчёты, заметки и библиотека PDF,
с работой мыши и клавиатуры и защитой заметок при обычном закрытии окна.
Перед выпуском выполняется дополнительное ревью всего проекта; замечания
собраны в docs/release-review-2026-11-03.md и устраняются до поставки.
Код и история сохраняются в Git, состояние и решения — в Notion, архивы и
доступные крупные файлы — в частной папке Google Drive. Недостающие оригиналы
и пароль архива подписи остаются явно указанными пробелами переноса.
