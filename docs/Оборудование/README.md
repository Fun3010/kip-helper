# Материалы по оборудованию

Единый каталог исходников: в папке модели или семейства находятся `ТД/` и `Фото/`.
Подпапки фото сохраняют группировку экземпляров и обозначения с шильдиков.
Общие стандарты размещены в `_Общие материалы/ТД/`.

Новые необработанные материалы загружайте в `docs/Входящие/Фото/` и
`docs/Входящие/ТД/`. После идентификации они переносятся сюда без изменения оригиналов.
Наличие документа в папке семейства не подтверждает его применимость ко всем
исполнениям: её нужно сверить по шильдику и редакции руководства.

- [Фотокаталог](Фотокаталог.md)
- [Реестр документов](../technical-documents.md)

Исходники автоматически не включаются в APK. Для приложения подготовленные
иллюстрации хранятся в `assets/illustrations/`.
