## Закрытые блокеры ревью

| ID | Причина | Исправление и доказательство |
|---|---|---|
| R18 | Windows-плагин SharedPreferences 2.4.1 сохраняет неудачную запись во втором кеше; reload не читает диск заново. После отказа сохранения черновик мог открыться как сохранённый. | Windows-заметки переведены на отдельные файлы с записью через временный файл и резервную копию. Миграция читает прежний JSON напрямую с диска. Настоящий плагин воспроизвёл RED: вместо saved A возвращал unsaved B. GREEN и нативная проверка подтверждают сохранность A после отказа и B после успешного сохранения. |
| R19 | Два процесса делили PDF-индекс и файл настроек; очередь одного процесса не защищала от второго. | Windows runner удерживает именованный Local mutex всю жизнь процесса. Повторный запуск активирует имеющееся окно и завершает новый процесс с кодом 0. Ошибка создания защиты останавливает запуск. CI проверяет второй запуск и освобождение защиты после завершения процесса. Локальный повтор тоже дал exit 0 при живом первом окне. |

Файлы заметок находятся в `getApplicationSupportDirectory()/notes/`;
имя — SHA-256 идентификатора прибора. Для отсутствующего или повреждённого
основного файла восстанавливается валидная резервная копия. Повреждённые
байты сохраняются отдельно; непрочитанные данные не заменяются пустой заметкой.
После успешного переноса каноничен новый файл: старый комплект `81ee137`
не читает этот формат и не должен запускаться параллельно с новым.

Android сохраняет прежнее хранилище; пакет и ключ подписи не менялись.
Новый APK в этом Windows-этапе не выпускался. Защита Local mutex действует
в одной Windows-сессии; межсессионная многопользовательская работа не заявлена.

## Границы приёмки и состояние PR

Блокеры R18/R19 устранены и проверены. PR можно перевести из черновика
в готовность к ревью/слиянию после успешных проверок текущей вершины.
Автоматическое слияние не включается.

Захват окна на этом ПК возвращал `FrameArrived timed out` / `window capture
timed out`, поэтому пиксельная визуальная приёмка и физический клик X не
засчитывались. Сохранены реальные AX-состояния, дисковые проверки и коды
выхода. Ввод клавиш шёл через Windows, не через framework key events;
это не заявление о проверке человеком физической клавиатуры.

Владелец подтвердил, что проверяет окно вручную; автоматическое управление
ему передано. Результат его проверки X пока не сообщён. Физический Android,
публикация в магазине и полный повтор сверки инженерных источников в этот
Windows-этап не входят.
