# Материалы закрытой версии RuStore

Название: КИП Помощник

Краткое описание:
Офлайн-справочник КИПиА: приборы, схемы, настройки и инженерные расчёты.

Полное описание:

КИП Помощник — справочник для специалистов по контрольно-измерительным приборам
и автоматике. Инструкции, иллюстрации и расчёты доступны без подключения к сети.

В приложении:
- Карточки SIPART PS2, СОКРАТ, РэмТЭК, СУ-1С, Biffi, СТМ-10, СТМ-30 и ИВА-8.
- Поиск по приборам, настройкам и диагностическим кодам; фильтрация по категориям.
- Иллюстрации ИВА-8 и СОКРАТ, схема аналоговых цепей СОКРАТ с увеличением.
- Температура и давление, прямой и обратный расчёт сигнала 4–20 мА.
- Термосопротивления Pt, П и М: температура, сопротивление и сигнал преобразователя.
- Светлая и тёмная темы.

Для каждого прибора указаны применимость и источники. Сведения зависят от
исполнения оборудования. Полные руководства по веб-ссылкам открываются отдельно
и требуют интернета. Приложение не управляет промышленным оборудованием.

Что нового:
Первая закрытая версия с постоянной подписью. Обновлённый интерфейс, категории,
иллюстрации ИВА-8 и СОКРАТ, инженерные калькуляторы.

## Поля, которые заполняет владелец

- Контакт разработчика: реальный email, сайт или другой доступный в форме контакт.
  Контакт пока не предоставлен; не подставлять вымышленный.
- Категория: подходящая из фактического списка консоли (инструменты/справочники).
- Возрастная маркировка: по анкете консоли; не заявлять рейтинг до заполнения анкеты.
- Тестировщик: только VK ID владельца, без публикации этого ID в репозитории.

## Сведения о данных для анкеты

В текущем приложении нет аккаунтов, рекламы, аналитики, покупок или сервера.
Поиск и расчёты выполняются на устройстве. Приложение не отправляет введённые
значения разработчику. При открытии внешнего источника пользователь переходит
в браузер, где действуют правила соответствующего сайта. При изменении SDK
или добавлении сетевых функций декларацию необходимо пересмотреть.

Для публичного распространения отдельно проверить права на фрагменты заводских
руководств и иллюстрации. Наличие PDF у разработчика само по себе не означает
разрешения на любое распространение. Закрытая сборка не заявлена публичной.
