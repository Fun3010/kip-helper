# Резервная копия карты позиций — 18.11.2026

Карта ГП / ДКС / УПМТ сохраняется на устройстве; добавлены команды «Сохранить
копию» и «Восстановить из копии». Файл JSON включает позиции всех площадок,
координаты, названия и идентификаторы связанных карточек. Фото, руководства и
личные заметки приборов в копию не входят. Экспорт создаёт отдельный файл в
месте, выбранном пользователем: системный диалог Android ACTION_CREATE_DOCUMENT
или системный диалог Windows через file_selector. Файл не загружается в сеть
приложением автоматически.

Восстановление заменяет все позиции всех трёх площадок только после явного
подтверждения, в диалоге указано число текущих и импортируемых позиций. До
записи проверяются версия формата, площадки, названия, координаты и типы;
размер ограничен 2 МиБ, неверный файл не меняет карту. Неизвестный идентификатор
прибора и дополнительные поля позиции сохраняются, в том числе при изменении
названия. При неудачной записи приложение сохраняет видимую прежнюю карту и
показывает ошибку. Отмена выбора или подтверждения не изменяет данные.

Данные объекта остаются личными: резервную копию и устройство следует хранить
так, как пользователь хранит проектные сведения. При сбое чтения существующей
карты импорт и экспорт заблокированы, чтобы случайно не заменить непонятные
данные; автоматического восстановления повреждённого хранилища нет.

Flutter-тесты моделируют выбор файлов и запись. Нативный Android-диалог,
конкретный файловый провайдер и перенос на физический телефон требуют отдельной
проверки; виджет-тесты и сборка не подтверждают эти действия. Для установленного
совместимого APK необходим исходный ключ подписи, который в этой среде отсутствует.
