# КИП / помощник

Android-приложение на Flutter/Dart: интерактивный справочник по приборам и инженерные калькуляторы. Карточки, поиск и расчёты работают без сети; полные руководства открываются отдельно в браузере.

[Журнал проекта и контекст для продолжения](PROJECT_JOURNAL.md) · [Результаты проверки](docs/validation-results.md)

**Статус на 14.09.2026:** подготовлена 1.2.1 (4) для закрытой альфы RuStore, пакет `ru.kiphelper.app`, постоянная подпись. Установка и запуск на Xiaomi проверены. В магазин пока не загружена. [Закрытое распространение](docs/private-distribution.md).

[План развития](docs/development-roadmap.md) · [Реестр технической документации](docs/technical-documents.md)

## Возможности

- Справочные модули с разделами, областью применимости и источниками.
- ИВА-8: характеристики и внешний вид; СОКРАТ: органы управления и аналоговая схема. Иллюстрации работают офлайн, открываются с увеличением до 6×.
- Поиск по каталогу и текстам разделов.
- Температура: °C, °F, K; давление: Па, кПа, МПа, бар, атм, мм рт. ст., мм вод. ст., кгс/см².
- Линейный сигнал 4–20 мА: прямое и обратное преобразование.
- НСХ Pt100/Pt500/Pt1000, 100П/50П, 100М/50М: температура ↔ сопротивление и ток заданного преобразователя.
- Светлая/тёмная темы, прокручиваемые экраны, копирование результатов.

Расчёт использует номинальную характеристику без погрешности конкретного датчика и сопротивления проводов. Pt100 и 100П имеют разные коэффициенты. Ток задаётся преобразователем и его диапазоном; сопротивление само по себе не является токовым сигналом.

## Настройка Android

В `pubspec.yaml` требуется Dart `^3.11.4`: используйте совместимый Flutter SDK. Текущее окружение: Flutter 3.41.6, Dart 3.11.4, JDK 21 из Android Studio. Android-проект задаёт AGP 8.11.1, Kotlin 2.2.20, Gradle 8.14 и Java target 17. Выбранную Java проверяйте через `flutter doctor -v`.

Установите Android Studio либо Android SDK command-line tools. Через SDK Manager установите SDK Platform, Build Tools, Platform Tools и Command-line Tools, требуемые установленным Flutter. Если сборка запросит NDK, установите указанную версию. `compileSdk`, `targetSdk`, `minSdk` и `ndkVersion` берутся из Flutter SDK. См. [официальную настройку Android](https://docs.flutter.dev/platform-integration/android/setup).

Пример PowerShell — замените пути своими:

```powershell
flutter config --android-sdk 'C:\Android\Sdk'
flutter config --jdk-dir 'C:\Java\jdk-17'
flutter doctor --android-licenses
flutter doctor -v
flutter pub get
```

Ознакомьтесь с лицензиями SDK и примите необходимые. `android/local.properties` содержит локальные пути `flutter.sdk` и `sdk.dir`; не переносите пути другого компьютера. Для первой загрузки зависимостей нужен интернет.

## Проверка и APK

Из корня проекта:

```powershell
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build apk --release
```

Для Windows также есть `scripts/build-android.ps1` с обязательными параметрами
`-FlutterSdk`, `-AndroidSdk`, `-Jdk`. Он выполняет получение зависимостей, анализ,
тесты и сборку, прекращая работу при ошибке.

APK для RuStore: [kip-helper-1.2.1-private.apk](dist/rustore/kip-helper-1.2.1-private.apk), 51 495 846 байт. Медиа и текст карточки в той же папке. Подпись и запуск на Xiaomi проверены. Канал публикации — только альфа с одним VK ID. Через USB:

```powershell
adb devices
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

При ручной установке откройте APK на телефоне и разрешите установку выбранному файловому менеджеру, если Android запросит это. Обновление существующего приложения требует той же подписи.

`scripts/test-apk.ps1 -Adb <путь-к-adb.exe> -Device <идентификатор>` устанавливает
APK через `install -r`, запускает приложение и проверяет его процесс. Скрипт
не удаляет установленное приложение при конфликте подписей.

Release использует постоянный ключ из `android/key.properties`; при отсутствии настройки сборка прекращается. Ключ и пароли исключены из Git, их защищённую резервную копию нужно хранить отдельно. Debug имеет отдельный идентификатор `ru.kiphelper.app.dev`. См. [официальную инструкцию выпуска](https://docs.flutter.dev/deployment/android).

## Архитектура и расширение

| Путь | Ответственность |
|---|---|
| `lib/main.dart`, `lib/app.dart` | Запуск, тема, навигация, каталог |
| `lib/models/guide.dart` | Модели карточек, разделов и источников |
| `lib/data/guides.dart` | Офлайн-содержимое |
| `lib/features/guides/guide_page.dart` | Универсальный экран карточки |
| `lib/domain/calculations.dart` | Формулы и валидация без Flutter |
| `lib/features/calculators/` | Экраны калькуляторов |
| `lib/widgets/calculator_widgets.dart` | Общие поля и результаты |
| `lib/services/open_source.dart` | Открытие источников |
| `test/` | Проверки формул и интерфейса |

Для нового прибора добавьте `InstrumentGuide` в `guides` с уникальным `id`, названием, категорией, исполнением в `scope`, разделами `GuideSection` и источниками `GuideSource`. Каталог подхватит запись автоматически. Сохраняйте HTTPS-ссылки, идентификатор руководства и редакцию; новый экран для текстового модуля не нужен.

Для нового калькулятора добавьте чистую функцию с проверкой входов в `domain`, опорные и граничные тесты, затем отдельный экран в `features/calculators` и карточку перехода в `app.dart`. Не помещайте инженерные формулы в UI.

## Применимость данных

Сведения о SIPART, СОКРАТ, РЭМТЭК и СУ-1С зависят от исполнения, блока управления и редакции паспорта. Карточки содержат указанную в них область применимости и не являются универсальным комплектом схем всех модификаций. Полные PDF не включены в APK. Если точная инструкция или распиновка не подтверждена для исполнения, справочник обозначает ограничение.

[Сравнение технологий](docs/technology-comparison.md) содержит результаты запуска расчётных прототипов Dart, TypeScript и Kotlin. Мобильные интерфейсы альтернатив не собирались. План проверок не заменяет журнал фактического запуска тестов и установки на устройство.
